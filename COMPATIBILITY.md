# Telescope Desk compatibility

Current candidate: 2.3.0b3. No public release/main push is authorized.

S50 and S50 Pro have documented historical Seestar Studio hardware tests. The
project developer also confirmed successful Live View on a real Seestar; the exact
model, firmware and codec of that test are unspecified. This evidence is retained.
The renamed/reduced candidate has NOT received a renewed hardware regression.
S30, S30 Pro and other models are not claimed hardware-tested.

Automated tests cover multiple sessions, optional telemetry, errors, image/video
processing, files, planning and settings. These do not prove all firmware variants.
The local portable/installed application has passed native smoke tests. A clean
external Windows PC and software-rendering-only host remain unverified.

See docs/compliance/MINIMIZATION_REPORT.md for exact results and limitations.
Historical device-specific records remain unchanged in
 docs/history/seestar-studio-b3/COMPATIBILITY.md.
